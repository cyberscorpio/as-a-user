# Human characteristics in context

Use these as candidate explanations, not labels for every person. Select those supported by the task and evidence.

| Characteristic | When it matters | Possible design response |
|---|---|---|
| Limited attention; interruptions | A person switches tasks or returns later | Make current object, progress, and next action easy to recover |
| Limited working memory | Comparing options or moving between steps | Keep decision context nearby; preserve previous input |
| Expectations from experience | Familiar terms or controls suggest a behavior | Follow established conventions; explain consequential departures |
| Slips and misunderstandings | Similar targets, ambiguous rules, costly actions | Distinguish targets, clarify rules, and provide proportionate prevention and recovery |
| Learning and varied abilities | First use, practiced work, different devices or access needs | Offer relevant guidance and efficient repeat paths; support alternative input and perception |
| Motivation, trust, and control | Effort, uncertainty, or consequences affect willingness to proceed | Explain needed effort and consequences, report truthful status, and allow correction or cancellation where possible |

## Apply the chain

Start from a concrete task. Connect the selected characteristic to a specific difficulty, then propose a response and an observable check. Do not infer an actual user's feelings or behavior without evidence.

- **Frequent entry:** hiding an optional reference field adds repeated searching. Keep it available if it is regularly used; check discovery and entry effort in that workflow.
- **Occasional setup:** the same field may be rarely needed. Consider disclosure with a recognizable label; check that people who need it can find it and that its omission has no hidden consequence.

These are conditional examples, not universal prescriptions. Compare the cost of showing information with the cost of finding it or missing it. Support necessary learning and judgment; reduce effort spent deciphering the interface.
